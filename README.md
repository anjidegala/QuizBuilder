# QuizMaster Pro — Home + Login + Signup + Admin

## Demo credentials
- User: student / 1234
- Admin: admin / admin123

## Student signup
Use Sign Up to create a student account. Accounts are stored in browser LocalStorage for this college demo.

## Main flow
Home -> Sign Up / Login -> User Dashboard
Home -> Login -> Admin -> Admin Dashboard

## Admin features
- Dashboard statistics
- Create courses
- Create quizzes
- Add question images
- Manage course/quiz data using LocalStorage

## Run
Extract the ZIP and open `index.html` in a browser.

Note: This is a frontend-only academic demo. LocalStorage authentication is not suitable for production security.
